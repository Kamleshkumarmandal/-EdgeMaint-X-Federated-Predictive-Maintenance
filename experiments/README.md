# Experiment tracking

Store versioned experiment configurations and compact result summaries here.

- configs/: dataset subset, preprocessing, model and training settings.
- results/: JSON or CSV metrics generated by completed runs.
- figures/: plots used in technical documentation (small exports only).

Do not commit raw data, model checkpoints, credentials, or results that were not actually produced. Each result record should identify the source dataset files, split strategy, random seed, package versions and commit SHA.
